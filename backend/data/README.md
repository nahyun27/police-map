# 전국 경찰관서 데이터

출처: 경찰청 전국경찰관서안내(2026.6.30 기준) 및 각 경찰서 홈페이지 부서별 연락처(2026.9.21~22 수집).
의뢰인이 제공한 원자료를 기반으로 한다.

`police_stations.json` — 시·도경찰청 18곳, 경찰서 262곳, 경찰단 1곳(인천국제공항경찰단), 부서·팀 2,273건.

## 2026-09-29 보정: 고성경찰서 중복

원자료에서 "고성경찰서"가 경남에 2건 중복 입력되고 강원 고성경찰서가 누락되어 있었다
(강원·경남 두 곳에 모두 "고성"이라는 지명이 있어, 부서 데이터를 합치는 과정에서 이름만으로
매칭하다 충돌한 것으로 추정). 아래 근거로 정정했다.

- 의뢰인이 제공한 마스터 목록(`police_stations_db.csv`)에는 애초에 두 관서가 정확히 구분되어 있었음
- 위키백과 및 강원경찰청 공식 홈페이지로 주소·URL 재확인
- 원자료의 부서 수집 원본 시트(`police_stations_db_3.xlsx` "수사부서_전국")에는
  "고성경찰서(강원)"·"고성경찰서(경남)"가 부서 목록과 함께 각각 존재 — 최종 병합 단계에서만 유실된 것을 확인

정정 결과: 강원 17곳 / 경남 23곳 (모두 정정 전 258개 관서 기준과 일치).

## 2026-10-02 보정: 광주·전남 주소의 "전남광주통합특별시" 오류

경찰서 좌표 지오코딩(`scripts/geocode_stations.py`) 준비 중 주소 매칭이 계속 실패하는 걸 보고
발견했다. 광주·전남 소속 관서 29곳(광주 6곳, 전남 23곳)의 주소 앞머리가 전부 "전남광주통합특별시"
로 돼 있었는데, 이런 행정구역은 실존하지 않는다. 원자료 병합 과정에서 "전남"과 "광주"의 광역단체명
템플릿이 잘못 합쳐진 것으로 보인다(고성경찰서 건과 같은 유형의 병합 오류).

실제 광역단체명(광주광역시/전라남도)으로 바로잡았다. 이 29곳은 지금까지 실제 사이트에도 잘못된
주소로 노출돼 있었다.
